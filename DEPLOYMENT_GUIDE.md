# Deployment Guide - NC State Neurotech Website

This guide explains how the website is built and deployed to the internet.

## Overview

This project is a **React + Vite** application deployed to **GitHub Pages**. When you deploy, your code is built into optimized static files and pushed to the `gh-pages` branch on GitHub, which automatically serves your site at `https://NCSUNeurotech.github.io/neurotech-website`.

## The Deployment Process

### Step 1: Build
When you run `npm run deploy`, it first runs `npm run build`:
- **Vite** bundles all your React components into optimized files
- All files are placed in the `dist/` folder
- JavaScript and CSS are minified (made smaller for faster loading)
- Source maps are created (helps debug in production)

**Output files:**
- `dist/index.html` - Main HTML file
- `dist/assets/index-*.js` - Your bundled JavaScript (the `*` is a unique hash)
- `dist/assets/index-*.css` - Your bundled CSS styles
- `dist/CNAME` - Domain configuration file

### Step 2: Deploy
After building, it runs `npm run deploy` which uses the `gh-pages` npm package:
- Takes everything from the `dist/` folder
- Pushes it to the `gh-pages` branch on GitHub
- GitHub automatically publishes this branch as your live website

## How to Deploy Your Changes

### Simple 1-Step Deployment
```bash
npm run deploy
```

This is all you need! It automatically:
1. ✅ Builds your project (`npm run build`)
2. ✅ Deploys to GitHub Pages (`npx gh-pages -d dist`)

### Manual Steps (if needed)
If you want to run each step separately:

```bash
# Step 1: Build the project
npm run build

# Step 2: Deploy to GitHub Pages
npx gh-pages -d dist
```

## Key Configuration Files

### `vite.config.ts`
- **`base: '/'`** - Tells Vite to build for root path (not a subdirectory)
- **`publicDir: 'public'`** - Copies files from `public/` to `dist/` during build
- **`outDir: 'dist'`** - Output folder for built files
- **Custom plugin** - Copies `staticwebapp.config.json` during build (if it exists)

### `package.json`
```json
{
  "scripts": {
    "predeploy": "npm run build",    // Runs automatically BEFORE deploy
    "deploy": "npx gh-pages -d dist" // Pushes dist/ to gh-pages branch
  }
}
```

The `predeploy` script ensures your build is always up-to-date before deploying!

## Monitoring Deployment

After running `npm run deploy`:
1. Check GitHub Actions on your repo's GitHub page
2. Look for the `pages build and deployment` workflow
3. Once it shows ✅ **passed**, your changes are live
4. Visit `https://NCSUNeurotech.github.io/neurotech-website` to see them

**Note:** There may be a 1-2 minute delay between deployment and your changes appearing online.

## Troubleshooting

### "npm: command not found"
- Install Node.js from [nodejs.org](https://nodejs.org)
- Run `npm install` to download project dependencies

### Build fails with errors
- Check the error message in the terminal
- Common fixes:
  ```bash
  npm install                  # Reinstall dependencies
  npm run build               # Try building again
  ```

### Changes didn't show up
- Hard refresh your browser (Ctrl+Shift+R or Cmd+Shift+R)
- Check GitHub Actions to confirm deployment succeeded
- Wait 1-2 minutes for GitHub Pages to update

### gh-pages permission error
- Make sure you're logged into GitHub with a token
- On Windows: Check that Git Bash credentials are saved
- On Mac/Linux: Check `~/.netrc` or use `gh auth login`

## GitHub Pages Configuration

Your site is configured in GitHub:

1. **Repository**: `NCSUNeurotech/neurotech-website`
2. **Deployment source**: `gh-pages` branch (automatic)
3. **Custom domain**: `CNAME` file (points to your domain)
4. **Live URL**: https://NCSUNeurotech.github.io/neurotech-website

The `public/CNAME` file is copied to `dist/CNAME` during build, which tells GitHub Pages to use your custom domain.
